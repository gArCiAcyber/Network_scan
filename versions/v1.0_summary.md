# Hylianscan v1.0.0 Summary

## Release Scope

Hylianscan v1.0.0 is the first stable release of the project as a standard-library-first reconnaissance tool for authorized targets. The release focuses on practical TCP scanning, protocol-aware service probing, optional passive discovery orchestration, clean TXT/JSON evidence reporting, and a tested CLI workflow suitable for labs, portfolio review, and defensive security learning.

## Core Capabilities

- Native TCP connect scanning with custom ports, ranges, top-port selection, and full-range support.
- Built-in TCP port profiles for quick, web, mail, admin, and bug bounty triage workflows.
- Scan stances with configurable workers, timeout, and max-rate pacing.
- Protocol-aware probing for HTTP, HTTPS, SMTP, FTP, IMAP, POP3, TLS, and common alternate web ports.
- STARTTLS-style upgrade probing for SMTP, IMAP, POP3, and FTP when services advertise support.
- HTTP status, redirect, header, content-type, cookie, and security-header metadata extraction.
- TLS certificate metadata collection with expiry, hostname mismatch, and basic risk explanation data.
- Passive subdomain discovery orchestration through optional Subfinder and Amass executables.
- Existing Nmap XML import mode for single-host XML evidence without running Nmap.
- Optional live Nmap service/version enrichment after native TCP scanning, scoped only to ports Hylianscan already found open.
- Human-readable TXT reports and structured JSON reports for TCP scans, passive discovery, Nmap XML import, and optional Nmap enrichment.
- Runtime current-working-directory output behavior for installed and source-run workflows.

## Packaging And Validation

- Source-run workflow remains supported with `python hylianscan.py`.
- `pipx` and source-based install metadata are provided through `pyproject.toml`.
- GitHub Actions cover unit tests and pipx installation.
- `scripts/validate_release.py` validates CLI metadata, Nmap XML fixture import, runtime output-root behavior, compile checks, unit tests, packaging dry-run, and Git whitespace checks.
- The test suite uses Python `unittest` and includes pure unit tests plus safe localhost mock-service coverage.

## Operational Boundaries

Hylianscan is intended for authorized reconnaissance, lab environments, defensive validation, and learning. Nmap, Subfinder, and Amass are optional external tools and must be installed separately when their related features are used. This release does not add crawling, exploit execution, UDP scanning, OS detection, NSE execution, or aggressive Nmap modes.
