# Roadmap

These ideas build on Hylianscan's existing probe registry, passive-provider flow, and structured reports.

- [ ] Detect DNS wildcard responses during passive discovery so generated names can be distinguished from provider findings.
- [ ] Add LDAP STARTTLS through the existing protocol probe registry and structured TLS reporting.
- [ ] Add reusable TXT report templates while keeping JSON as the stable machine-readable format.
- [ ] Expand protocol fingerprinting through focused probes that preserve raw evidence and report uncertainty.
- [ ] Publish to PyPI after release validation and the `pipx` install path are stable.
